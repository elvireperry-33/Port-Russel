Documentation de l'API - Port de Plaisance Russell

Retour au Dashboard

Gestion des Catways

GET /catways : récupérer la liste de tous les catways.

GET /catways/:id : récupérer les informations d'un catway.

POST /catways : créer un nouveau catway.

PUT /catways/:id : modifier l'état d'un catway.

DELETE /catways/:id : supprimer un catway.

Gestion des réservations

GET /catways/:id/reservations : récupérer les réservations d'un catway.

GET /catway/:id/reservations/:idReservation : récupérer une réservation en particulier.

POST /catways/:id/reservations : créer une réservation.

PUT /catways/:id/reservations : modifier une réservation.

DELETE /catway/:id/reservations/:idReservation : supprimer une réservation.

Gestion des utilisateurs

GET /users/ : récupérer la liste des utilisateurs.

GET /users/:email : récupérer un utilisateur grâce à son email.

POST /users/ : créer un utilisateur.

PUT /users/:email : modifier un utilisateur.

DELETE /users/:email : supprimer un utilisateur.

Authentification

POST /login : connecter un utilisateur avec son email et son mot de passe.

GET /logout : déconnecter l'utilisateur.
